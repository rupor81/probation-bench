# office-generalist

A small trading company (`office.example`, today is 2026-03-31) with four managers: finance, sales, operations and
the CEO, plus company-wide rules. The agent is a new assistant who takes assignments from all of them.

| | |
| --- | --- |
| Tasks | 58, each in three orders (`stream-full-a/b/c.yaml`); `stream-finance-8.yaml` is an eight-task smoke slice |
| Hidden rules | 33 (finance 7, sales 4, operations 4, CEO 3, company-wide 15), five of them overgeneralization traps |
| Tables | clients, invoices, quotes, orders, stock, suppliers, staff, calls |
| Wiki | payment terms, ordering, quotes, invoices, calendar, staff discount, bulk import, an outdated policy page, a confidential page |
| Second half | a tempo line on every prompt and a distractor mail |

Clients, suppliers, people and addresses are fictional.
